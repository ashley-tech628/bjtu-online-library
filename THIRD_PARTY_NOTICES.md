# Third-party and inherited source

Backend foundation/framework code contains pre-existing utility and security scaffolding, including original author comments. Their precise upstream repository and license were not present in the recovered course folder; original notices are retained and no blanket relicensing is applied.

The frontend includes TinyMCE distribution files under `t11-web/public/tinymce-dev`. Retain their license notices. Other dependency names and versions are recorded in the Gradle manifests and npm lockfile; their upstream licenses apply.

Third-party ebook contents and original database dumps are excluded from this release.
