# Authorship and contributions

This is a team project completed for the Distributed Systems course. Xinying Liu (Ashley Liu) served as team lead and was the primary contributor to the Spring Boot backend, API design, database design and frontend/backend integration.

The individual contribution report records database construction, backend and authentication design, JSON APIs, integration debugging, Gradle packaging, and collaboration on catalog search, pagination, categories and sorting. Team leadership included selecting the stack, coordinating feature planning, supporting development setup and debugging teammates' integration issues.

The recovered code uses MyBatis and MyBatis Dynamic SQL. The original report describes MyBatis Plus; dependency manifests and source imports determine the implementation names used in this public README.

The frontend, reports and overall delivery were team efforts. Framework and utility packages include earlier scaffold code and retain their original author comments. Their presence does not imply sole authorship by Ashley Liu. The public release does not assign a new blanket license to these inherited files.
